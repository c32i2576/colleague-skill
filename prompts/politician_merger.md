# 政治人物增量 Merge Prompt

## 任務

你將收到：
1. 現有的 `political.md` 內容
2. 現有的 `persona.md` 內容
3. 現有的 `meta.json` 摘要（如有）
4. 新的政治人物原材料（投票記錄、演說、訪談、社媒、媒體評論等）

你的任務是判斷新內容應該更新哪個部分，並輸出增量更新內容。

**原則：只追加增量，不覆蓋已有結論。若新材料與既有內容衝突，按證據權重判斷並讓用戶確認。**

證據權重：投票/行政決策 > 政策文件/競選綱領 > 演說/辯論/質詢 > 社交媒體/訪談/記者會 > 媒體評論/對手攻擊/民調。

---

## Step 1：分類判斷

將新內容中的每條信息歸類：

| 信息類型 | 歸入 |
|---------|------|
| 政策立場、法案投票、行政決策、正式政策文件 | `political.md` 的「政策立場」或「政治資產知識庫」 |
| 修辭框架、口號、辯論攻防、受眾話術 | `political.md` 的「修辭武器庫」 |
| 結盟、黨內經營、媒體策略、危機處理 | `political.md` 的「政治操作手冊」 |
| 口頭禪、語氣、情緒反應、壓力下直覺 | `persona.md` 的 Layer 2 / Layer 3 |
| 盟友/對手/媒體/選民互動 | `persona.md` 的 Layer 4 |
| 紅線、雷區、禁忌話題 | `persona.md` 的 Layer 5 |
| 證據來源、置信度、推斷項 | `political.md` 或 `persona.md` 的證據邊界，同步建議更新 `meta.json` |

---

## Step 2：檢查衝突

對比新內容與現有內容：

- 如果新內容補充了現有信息：直接追加
- 如果新內容確認了現有信息：記錄為「證據增強」，避免重複
- 如果新內容與現有信息矛盾：輸出衝突提示

衝突提示格式：

```markdown
發現衝突：
- 現有結論：{現有描述}
- 新材料：{新內容描述}
- 新材料來源：{來源 + 日期，如有}
- 證據權重判斷：{新材料權重 vs 現有結論權重}
- 建議：{保留現有 / 更新為新材料 / 兩者並存，標註「利益取向 vs 公開敘事」}
```

當投票/決策與公開演說衝突時，優先建議「兩者並存」：
- `利益取向` 寫入 political.md 的政策立場
- `公開敘事` 寫入修辭武器庫或 persona 的表達風格

---

## Step 3：生成更新 Patch

對 `political.md` 的更新，輸出格式：

```markdown
=== political.md 更新 ===

[追加到「政策立場 / {議題}」]
- {新增立場}
  - 證據等級：{硬證據/公開表述/外部觀察/推斷}
  - 來源：{出處}

[追加到「修辭武器庫」]
- {新增話術或敘事框架}

[追加到「政治資產知識庫」]
- 類型：{投票/決策/演說/訪談/社媒/外部觀察}
  資產："{原話或事件}"
  來源：{出處}
  證據等級：{等級}
  可用場景：{場景}

[無更新] 或 [以上章節有更新]
```

對 `persona.md` 的更新，輸出格式：

```markdown
=== persona.md 更新 ===

[追加到「Layer 0：核心政治人格」]
- {新行為規則}（證據等級：{等級}）

[追加到「Layer 2：公眾表達風格」]
- 新口頭禪："{xxx}"
- 新場景話術：{場景 + 話術}

[追加到「Layer 4：政治人際行為」]
- {新行為描述}

[追加到「Layer 6：證據邊界」]
- {新增證據或待驗證推斷}

[無更新] 或 [以上章節有更新]
```

對 `meta.json` 的更新建議，輸出格式：

```markdown
=== meta.json 更新建議 ===
- knowledge_sources：追加 {N} 個來源
- evidence_counts：hard_evidence +{N}, public_statements +{N}, external_observations +{N}, inferences +{N}
- spectrum：{是否需要更新坐標與置信度}
```

---

## Step 4：生成更新摘要

向用戶展示：

```markdown
本次更新摘要：
- political.md：追加了 {N} 條新信息（{簡要描述}）
- persona.md：追加了 {N} 條新信息（{簡要描述}）
- meta.json：建議更新 {N} 個字段
- 發現 {N} 處衝突，需要你確認

版本將從 {vN} 升級到 {vN+1}。
確認應用更新？
```
