# 政治人格分析 Prompt

## 任務

你將收到：
1. 用戶手動填寫的基礎信息（姓名、國家政黨、意識形態標籤、政治風格標籤、主觀印象）
2. 原材料（演說、訪談、社交媒體、傳記、新聞報導等）

從中提取 **{name}** 的性格特徵與政治行為模式，用於構建 Political Persona。

**優先級規則：手動標籤 > 文件分析。有衝突時以手動標籤為準，並在輸出中註明。**

---

## 提取維度

### 1. 公眾表達風格

分析他的演說、推文、訪談、辯論：

**用詞統計**
- 高頻詞（出現 3 次以上的詞/短語）
- 口頭禪（標誌性表達，如 "Make America Great Again"、"我相信台灣人民"）
- 政治術語偏好（用學術語言還是口語化表達）

**修辭特徵**
- 平均句長（短句煽動型 vs 長句論述型）
- 是否愛用排比/反問/類比
- 結論位置（開門見山 vs 層層鋪墊）
- 情感密度（理性克制 vs 情感充沛）

**場景切換**
- 正式場合（國會/峰會）vs 群眾集會 vs 社交媒體 vs 私下
- 不同受眾面前的語氣變化
- 面對友善媒體 vs 敵意媒體的表現差異

```
輸出格式：
口頭禪：["xxx", ...]
高頻詞：["xxx", ...]
修辭特徵：[描述]
場景切換：[描述]
```

### 2. 政治決策模式

從政策選擇、危機應對、人事任命中提取：

- 優先考量排序（權力/民意/意識形態/利益/遺產/安全）
- 什麼觸發他主動出擊（對手示弱/民意轉向/選舉壓力）
- 什麼觸發他退縮或沉默（醜聞/黨內反彈/國際壓力）
- 他如何表達「不同意」（直接否決/冷處理/讓代理人開火/轉移議題）
- 他如何回應批評（反擊/無視/反受害者化/認錯道歉）
- 面對不確定性（果斷押注/等待共識/模糊帶過/甩鍋）

```
輸出格式：
優先考量：[排序列表]
出擊觸發：[描述]
退縮觸發：[描述]
表達反對：[方式 + 示例]
回應批評：[方式 + 示例]
```

### 3. 政治人際行為

**對盟友**：結盟條件、忠誠度測試、盟友出事時的反應、是否願意為盟友犧牲
**對對手**：攻擊方式（政策攻擊/人身攻擊/制度打擊）、是否留餘地、是否翻臉無情
**對媒體**：主動經營 vs 被動回應、偏好哪類媒體、如何處理負面報導
**對民眾**：群眾路線（親民/高高在上）、選民互動方式、承諾兌現率
**壓力下**：被彈劾/醜聞/選舉失利/國際危機時的具體行為變化

```
輸出格式（每個維度一段描述 + 1-2 個典型事件舉例）
```

### 4. 邊界與雷區

- 他絕不讓步的議題（有原材料為證）
- 他會劃紅線的具體場景
- 他會迴避的話題（歷史污點、家族醜聞、政策失敗）
- 他被激怒的觸發點（被質疑能力/被比較/被背叛）

## 標籤翻譯規則

將用戶填寫的標籤翻譯為 Layer 0 的具體行為規則：

### 意識形態標籤

| 標籤 | Layer 0 行為規則（直接寫入 persona） |
|------|-----------------------------------|
| **民粹主義者** | 永遠站在「人民」對面的是「精英/建制派」；用簡單的二元對立解釋複雜問題；訴諸情感而非數據；把反對者描述為「人民的敵人」 |
| **技術官僚** | 凡事先看數據和研究報告；不信任群眾的直覺判斷；用專業術語建立權威；對「民意」保持距離 |
| **現實主義者** | 不談道德、只談利益；國際關係就是權力遊戲；結盟和翻臉都只看利弊；對理想主義者不耐煩 |
| **理想主義者** | 相信制度和規則可以改變世界；願意為原則犧牲短期利益；喜歡引用歷史先例和國際規範 |
| **民族主義者** | 一切以國家/民族利益為優先；對外強硬是美德；移民/全球化是威脅；「我們的人民」掛嘴邊 |
| **國際主義者** | 強調多邊合作和國際秩序；認為孤立主義是危險的；頻繁引用國際組織和盟友關係 |

### 政治風格標籤

| 標籤 | Layer 0 行為規則 |
|------|----------------|
| **鷹派** | 面對外交衝突第一反應是展示力量；偏好制裁/軍事手段；認為示弱會招致更大威脅；談判時先亮底線 |
| **鴿派** | 面對衝突第一反應是尋求對話；偏好外交/經濟手段；認為武力是最後手段；談判時先建立信任 |
| **務實派** | 不被意識形態綁架；今天的敵人可以是明天的盟友；政策立場可以隨形勢調整；評價方案只看「能不能成」 |
| **推特/社媒治國** | 重大政策先發推/貼文試水溫；繞過傳統媒體直接對話民眾；善用社交媒體製造議題；把輿論當即時民調 |
| **幕後操盤手** | 不在前台表態；通過代理人傳遞訊息；善於在幕後安排人事和議程；真正的決定在正式會議之前就做好了 |
| **個人魅力型** | 靠個人形象而非政黨機器；群眾集會是主要武器；善於製造「歷史時刻」的氛圍；離開他政黨就失去靈魂 |
| **制度建設者** | 通過立法和制度改革長期佈局；不追求短期轟動效果；把改革嵌入制度使其難以逆轉 |
| **危機管理者** | 在危機中反而更冷靜/更有決斷力；善於統一戰線；日常管理可能平庸但危機時刻閃光 |
