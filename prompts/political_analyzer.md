# 政治能力分析 Prompt

## 任務

你將收到 **{name}** 的原材料（演說稿、投票記錄、政策文件、訪談、社交媒體等）。
從中提取他的政治能力與方法，用於構建 Political Capability。

**原則：只提取有據可查的內容。不要推斷，有依據才寫，沒有就標注「原材料不足」。**

**證據權重：投票/行政決策 > 政策文件/競選綱領 > 演說/辯論/質詢 > 社交媒體/訪談/記者會 > 媒體評論/對手攻擊/民調。**

當不同來源衝突時，不要合併成模糊結論；直接標註：
- `利益取向`：投票、行政決策、正式政策文件呈現的方向
- `公開敘事`：演說、辯論、社媒呈現給選民的說法
- `衝突點`：兩者具體差在哪裡

---

## 通用提取維度（所有政治人物適用）

### 1. 政策立場與投票記錄

從原材料中識別：
- 他的核心政策主張（經濟、外交、社會、環境等）
- 關鍵法案的投票記錄（贊成/反對/棄權，及其模式）
- 政策立場的演變軌跡（哪些議題上有過轉向）
- 與黨綱的一致程度（忠誠黨員 vs 獨立派）
- 每個立場的證據等級：`硬證據` / `公開表述` / `外部觀察` / `推斷`
- 投票與話術不一致時，分開寫「實際行動」和「對外說法」

```
輸出格式：
核心主張：
  - 議題：[立場]
    證據：[來源類型 + 出處 + 日期（如有）]
    證據等級：[硬證據/公開表述/外部觀察/推斷]
投票模式：[描述一致性與例外]
立場演變：[時間線 + 轉向原因 + 證據]
黨內定位：[忠誠度評估 + 證據]
衝突點：[利益取向 vs 公開敘事，如無則寫「未發現」]
```

### 2. 修辭與論述能力

從演說和辯論中提取：
- 核心敘事框架（他用什麼故事/隱喻解釋世界）
- 辯論策略（攻擊、防守、轉移、訴諸情感/邏輯/權威）
- 標誌性口號和金句
- 面對尖銳提問時的應對模式
- 受眾針對性（對不同群體的話術切換）

```
輸出格式：
核心敘事：[框架描述]
辯論策略：[主要戰術列表]
標誌性口號：["xxx", ...]
應對尖銳提問：[模式描述 + 示例]
受眾切換：[不同場景的話術差異]
```

### 3. 政治操作能力

從政治生涯和媒體報導中提取：
- 結盟與對抗模式（誰是盟友、誰是對手、如何選擇）
- 黨內經營（如何鞏固權力基礎）
- 媒體策略（如何控制敘事、製造議題）
- 危機處理能力（醜聞/失敗時的應對）
- 選舉策略（動員方式、選區經營）

```
輸出格式：
結盟模式：[描述]
黨內經營：[描述]
媒體策略：[描述]
危機處理：[模式 + 案例]
選舉策略：[描述]
```

### 4. 政治資產與經驗知識庫

他的核心政治資產（直接引用原話或事件）：

```
- 類型：投票/決策/演說/訪談/社媒/外部觀察
  資產："{原話或事件總結}"
  來源：{出處}
  證據等級：硬證據/公開表述/外部觀察/推斷
  可用方式：{在什麼場景下可作為該政治人物的回應依據}
```

### 5. 政治光譜坐標

根據硬證據優先、公開表述次之的規則，給出兩軸坐標：

```
經濟軸：{1-5}（{極左/中偏左/中間/中偏右/極右}）
權威軸：{1-5}（{極度自由/偏自由/中間/偏威權/極度威權}）
依據：
  - 經濟軸：[投票/政策/公開表述證據]
  - 權威軸：[投票/政策/公開表述證據]
置信度：高/中/低
不確定項：[缺少哪些資料]
```

## 職位專項提取

根據 {name} 的職位，重點提取對應維度：

---

### 🏛️ 國家元首（總統/主席/首相）

**執政能力**：
- 內閣/團隊組建策略（用人哲學）
- 行政命令/政策推動方式
- 與立法機關的互動模式（合作/對抗/繞過）
- 國際場合的表現（峰會、雙邊會談風格）

**領導風格**：
- 決策圈大小（集中 vs 分散）
- 對異議的容忍度
- 在重大事件中的決策速度
- 國內 vs 國際議題的時間分配

---

### 🏢 立法者（國會議員/立法委員/人大代表）

**立法能力**：
- 提案數量與通過率
- 專注的委員會與議題領域
- 跨黨派合作的意願與成功率
- 質詢風格（尖銳/溫和/程序性）

**選區經營**：
- 與選民的互動方式
- 地方議題 vs 全國議題的平衡
- 利益輸送/服務選區的模式

---

### 🏘️ 地方首長（市長/州長/省長）

**治理能力**：
- 核心施政方向
- 預算優先級
- 與中央政府的關係
- 地方經濟發展策略

**政績**：
- 任內重大建設/改革
- 爭議性決策及後果
- 民調/滿意度變化

---

### ⚔️ 反對派/在野領袖

**抗爭策略**：
- 動員方式（街頭/社交媒體/議會）
- 與執政黨的互動模式（全面對抗/議題合作/策略模糊）
- 國際連結（是否尋求國際支持）

**替代方案**：
- 是否提出具體政策替代方案
- 還是純粹批評

---

### 🌐 國際組織/外交官

**談判能力**：
- 談判風格（強硬/靈活/拖延）
- 多邊 vs 雙邊偏好
- 在關鍵國際議題上的立場

**影響力**：
- 在國際場合的話語權
- 與其他國家的關係網絡

---

## 輸出要求

- 語言：中文
- 沒有信息的維度：標注 `（原材料不足，建議追加相關文獻）`
- 有原文依據的結論：加引號標注原話，註明出處
- 輸出結果直接用於生成 political.md，要求具體可操作，不要寫「可能」「傾向於」這類模糊表述
- 每條核心立場都要能追溯到至少一個來源；做不到時只能放入「推斷/待驗證」而不能放入硬立場
