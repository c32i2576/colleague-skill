# 政治人格分析 Prompt（Expression DNA Analyzer）

> 從六軌研究的一手語料中量化提取此人的**表達 DNA**——句式指紋、風格光譜、口癖與禁忌詞、敘事框架。
> 本 Prompt 產出 PART C（Expression DNA）的內容。

---

## 任務

你將收到 **{name}** 的一手語料（演說、訪談、社媒、辯論稿）。
目標：把「風格」從空話（「有魅力、犀利」）變成**可驗證的量化指標**。

不處理立場（那是 `political_analyzer.md` 的工作）；只處理「他怎麼說話」。

---

## Step 1：句式指紋（從 20 段隨機樣本統計）

從語料中隨機取 20 段（各 100-300 字），統計：

| 維度 | 測量方式 | 結果 |
|------|---------|------|
| 平均句長 | 總字數 / 總句數 | {X} 字 |
| 疑問句比例 | 疑問句 / 總句 | {X}% |
| 類比密度 | 類比數 / 千字 | {X} |
| 第一人稱使用率 | 「我」+ 「我們」頻率 | {X}% |
| 確定性語氣 | 「一定/絕對/顯然」 vs 「也許/可能」 | 偏向 {斷言/謹慎} |
| 攻擊頻率 | 指名批評他人 / 千字 | {X} |
| 情緒詞密度 | 情緒形容詞 / 千字 | {X} |

**附**：樣本來源列表（哪 20 段、出處、日期），確保可追溯。

---

## Step 2：風格光譜（六條軸，各 0-5 給分並說明依據）

```
正式   0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5   口語
抽象   0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5   具體
謹慎   0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5   斷言
菁英   0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5   庶民
結論先行 0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5  鋪陳型
數據驅動 0 ─ 1 ─ 2 ─ 3 ─ 4 ─ 5  敘事驅動
```

每條軸必須引用 1-2 段原文做依據。

---

## Step 3：口癖清單（高頻標誌性表達）

列出此人**明顯高於常人**的口頭禪或標誌性短語：

```
口癖：{表達}
頻率：{出現次數 / 千字}
典型用法：{引用一段原文}
```

**規則**：
- 只列真正**區別於一般政治人物**的，不要列「各位鄉親」「台灣人民」這種所有政客都用的
- 3-7 個為宜

---

## Step 4：禁忌詞（此人從不用的詞）

找出此人**明顯迴避**的詞或概念：

```
禁忌詞：{詞}
證據：{在該議題語料中找不到此詞，改用 Y 替代}
推斷原因：{為何迴避，如政治正確考量、派系禁忌}
```

例：
- 蔡英文迴避「統一」，改用「共同未來」
- 川普迴避「對不起」「錯誤」，改用「假新聞」「完美通話」

---

## Step 5：標誌性敘事框架

3-5 個此人**反覆使用**的故事/隱喻骨架：

```
敘事：{框架名稱，例如「美國優先」「庶民總統」「拚經濟」}
結構：{此框架的敘事結構，誰是主角、誰是反派、結局是什麼}
使用場景：{什麼議題會啟動此敘事}
範例：{1-2 段原文}
```

---

## Step 6：場景切換（對不同受眾的語氣差異）

政治人物對不同受眾會切換：

```
對黨內支持者：{語氣特徵 + 範例}
對反對陣營：{語氣特徵 + 範例}
對國際媒體：{語氣特徵 + 範例}
對基層選民：{語氣特徵 + 範例}
```

如果某場景無語料 → 標「無資料」，不要編。

---

## 輸出格式

最終交付一個 `persona.md` 草稿：

```markdown
# {name} — 表達 DNA

## 句式指紋
{表格}

## 風格光譜
{六條軸評分 + 依據}

## 口癖
- ……

## 禁忌詞
- ……

## 標誌性敘事
### 敘事 1：……

## 場景切換
- 對黨內：……
```

## 自檢

- [ ] 每項評分都有原文依據？
- [ ] 口癖是此人**特有**的，不是通用政客話術？
- [ ] 有沒有誠實標註「某場景無語料」？
- [ ] 刪掉名字後，看這份 DNA 能認出是誰嗎？
