# 政治能力分析 Prompt（Political Capability Analyzer）

> 本 Prompt 用於從六軌研究成果中提取政治人物的**心智模型 + 決策啟發式 + 硬證據**。
> 搭配 `references/extraction-framework.md` 的三重驗證與證據權重規則使用。

---

## 任務

你將收到 **{name}** 的六軌研究輸出（`research/01-speeches.md` … `06-timeline.md`）及用戶填寫的基礎資訊。
目標：提取**政治能力**——此人如何思考政治、如何決策、有哪些硬證據撐腰。

分成 **PART A（心智模型）** 和 **PART B（決策啟發式）** 和 **PART D 片段（硬證據摘要）** 三塊輸出。

**原則**：
- 只提取有據可查的內容。沒有依據標「資訊不足」。
- 投票/行政決策 > 政策文件 > 演說/辯論 > 社媒/訪談 > 媒體/民調。
- 衝突不抹平，並列「利益取向 vs 公開敘事 vs 衝突點」。

---

## Step 1：提取心智模型（PART A 用）

掃描六軌研究，找出此人反覆使用的**思考框架**。每個候選模型逐條走三重驗證：

### 三重驗證清單

對每個候選模型填表：

```
候選模型：{名稱，例如「交易觀」「工程師思維」「鬥爭哲學」}
  驗證 1 — 跨域復現：
    領域 A：{具體議題} + {證據}
    領域 B：{具體議題} + {證據}
    （至少 2 個不同議題領域才通過）
  驗證 2 — 生成力：
    對新議題「{X}」，此模型可推斷立場：{Y}
    （能生成新推斷才通過）
  驗證 3 — 排他性：
    與同黨/同光譜典型人物對比，此人獨特之處：{Z}
    （有明顯區分度才通過）
  結果：3 通過 → 心智模型 | 1-2 通過 → 降為啟發式 | 0 通過 → 剔除
```

**目標數量**：3-7 個通過三重驗證的模型。

### 常見政治心智模型類型（參考，非限定）

- **交易觀**：一切關係都是可談判的交易（deal-maker 型）
- **鬥爭哲學**：政治是敵我、零和（強派系型）
- **工程師思維**：用 KPI / 流程 / 平台解決政治（技術官僚型）
- **代言人模型**：我是某群體的聲音（民粹型）
- **歷史使命觀**：我在完成某個歷史任務（意識形態強者）
- **風險控制**：先避免輸，再談贏（穩健派）
- **敘事優先**：掌握故事就掌握政治（媒體型）

**務必**：模型名稱要具體到此人，避免套用通用標籤。

---

## Step 2：提取決策啟發式（PART B 用）

只通過 1-2 重驗證的、或雖不是「模型」但有清楚案例支撐的**可觸發規則**，寫成啟發式。

格式：

```
規則名：{短標籤}
觸發條件：{什麼情況會啟動}
行動：{具體怎麼做}
案例：{投票 / 發言 / 行動，含日期}
證據等級：硬證據 / 公開表述 / 外部觀察 / 推斷
```

**目標數量**：5-10 條。

---

## Step 3：提取硬證據摘要（PART D 片段用）

把**最硬的 10-20 條證據**條列出來，作為日後回應政策議題的底座：

```
議題：{議題名}
立場：{此人實際採取的行動}
證據：{投票 / 決策 / 政策文件 + 日期 + 出處}
公開敘事：{此人對外如何說}
衝突點：{有無差距？差在哪？}
```

---

## Step 4：輸出政治光譜坐標

基於以上分析，給出光譜坐標：

- **經濟**：1（左）- 5（右）= ?，依據 {關鍵投票/政策}
- **權威**：1（自由）- 5（威權）= ?，依據 {關鍵投票/政策}
- **置信度**：高/中/低
- **不確定的原因**：{如某軸投票記錄不夠多}

---

## 輸出格式

最終交付一個 `political.md` 草稿，三個區段：

```markdown
# {name} — 政治能力

## 心智模型（通過三重驗證）
### 模型 1：……（依 skill-template.md 的欄位）
### 模型 2：……

## 決策啟發式（案例驅動規則）
1. ……

## 硬證據摘要
- 議題 A：……

## 政治光譜
經濟 {X}/5｜權威 {Y}/5｜置信度 {高/中/低}
```

---

## 衝突處理提醒

當投票與口號衝突時，**不要合併**。直接寫：

```
利益取向（硬證據）：{方向 A}
公開敘事（演說/社媒）：{方向 B}
衝突點：{具體差異}
本 Skill 處理方式：以 A 為立場底座，以 B 為包裝話術
```
