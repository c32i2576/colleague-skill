# 政治人物基礎信息錄入腳本

## 開場白

```
我來幫你蒸餾這位政治人物的 Skill。只需要回答 3 個問題，每個都可以跳過。
```

---

## 問題序列

### Q1：代號/花名

```
這位政治人物怎麼稱呼？（全名、綽號或代號都行，多個字用 - 連接）

例：trump、tsai-ing-wen、macron
```

- 接受任意字符串
- 生成的 slug 統一用 `-` 連接
- 中文自動轉拼音再用 `-` 連接（"蔡英文" → `tsai-ing-wen`）
- 英文直接小寫 `-` 連接（"Donald Trump" → `donald-trump`）

### Q2：基本信息

把國家、政黨、現任/歷任職位、活躍年代放在一個問題裡：

```
用一句話描述他的基本信息——國家、政黨、職位、活躍年代，想到什麼寫什麼，跳過也行。

例：美國 共和黨 前總統 2016-2024
例：台灣 民進黨 前總統 2016-2024
例：法國 復興黨 現任總統 2017-
```

從用戶的回答中解析以下字段（缺失的留空）：
- **國家/地區**
- **政黨**
- **職位**（現任/歷任最高職位）
- **活躍年代**

#### 政治體制參考表

| 體制 | 典型國家 | 關鍵職位 |
|------|---------|---------|
| 總統制 | 美國、巴西、韓國 | 總統、副總統、國務卿/外交部長 |
| 半總統制 | 法國、台灣、俄羅斯 | 總統、總理/行政院長 |
| 議會制 | 英國、德國、日本 | 首相/總理、黨魁 |
| 一黨制 | 中國、越南 | 總書記、國家主席、總理 |
| 君主立憲 | 英國、日本、泰國 | 首相、國王/天皇（虛位） |

### Q3：政治畫像

把意識形態、政治風格、標籤、你對他的印象全部合在一起：

```
用一句話描述他的政治風格——意識形態、政治光譜位置、個人風格、你對他的印象，
想到什麼寫什麼，跳過也行。

例：右翼民粹 鷹派 推特治國 商人思維 語不驚人死不休
例：務實中間派 善於談判 低調但心狠手辣
例：左翼進步派 環保主義 年輕有魅力 但缺乏執行力
例：#現實主義 #民粹主義 #鷹派 經濟右/威權偏高 先談利益再談價值
```

從用戶的回答中識別並提取以下字段（缺失的留空）：
- **政治光譜坐標**：從下方維度定位
- **意識形態標籤**：從下方標籤庫匹配，也接受自定義
- **政治風格標籤**：從下方標籤庫匹配
- **主觀印象**：無法歸類的自由描述，直接保留原文

標籤輸出時統一加 `#`，例如 `#現實主義`、`#民粹主義`、`#鷹派`、`#鴿派`。如果用戶沒有提供坐標，先根據描述做低置信度初判，後續必須用投票記錄或正式政策文件校正。

#### 政治光譜坐標

兩個維度，各 5 級：

**經濟軸**（左 ↔ 右）：
1. 極左（計劃經濟、全面國有化）
2. 中偏左（福利國家、累進稅、強監管）
3. 中間（混合經濟、務實調控）
4. 中偏右（自由市場、減稅、去監管）
5. 極右（極端自由放任、私有化一切）

**權威軸**（自由 ↔ 威權）：
1. 極度自由（無政府傾向、最小政府）
2. 偏自由（保障個人權利、限制政府權力）
3. 中間（平衡安全與自由）
4. 偏威權（強調秩序、擴大政府權力）
5. 極度威權（一黨專政、全面控制）

```
示例坐標：
Trump → 經濟 4（中偏右）/ 權威 4（偏威權）
Sanders → 經濟 2（中偏左）/ 權威 2（偏自由）
習近平 → 經濟 1-2（極左到中偏左）/ 權威 5（極度威權）
Macron → 經濟 3-4（中間到中偏右）/ 權威 3（中間）
```

#### 意識形態標籤庫

**經濟意識形態**：
- **新自由主義** — 自由市場至上、私有化、去監管、全球化
- **社會民主主義** — 福利國家、累進稅、公共服務、勞動保障
- **國家資本主義** — 政府主導經濟、國企控制命脈產業
- **社會主義** — 生產資料公有、計劃經濟
- **重商主義/經濟民族主義** — 貿易保護、關稅壁壘、產業政策

**社會意識形態**：
- **進步主義** — 推動社會變革、支持少數群體權利
- **保守主義** — 維護傳統價值、家庭、宗教
- **自由意志主義** — 個人自由最大化、政府最小化
- **威權主義** — 強調秩序、集中權力
- **民族主義** — 國家/民族利益優先
- **國際主義** — 多邊合作、國際秩序

#### 政治風格標籤庫

**修辭風格**：
- **民粹主義者** — 對立精英與人民、簡化議題、訴諸情感
- **技術官僚** — 數據驅動、專業導向、迴避情感訴求
- **煽動者** — 極端言論、製造恐懼/憤怒、陰謀論
- **調和者** — 尋找共識、模糊立場、兩邊討好
- **意識形態戰士** — 立場鮮明、不妥協、把一切議題意識形態化

**決策風格**：
- **鷹派** — 強硬、好鬥、偏好軍事/制裁手段
- **鴿派** — 溫和、外交優先、偏好談判/對話
- **務實派** — 不拘意識形態、以結果論英雄
- **教條派** — 嚴格遵循意識形態、原則不可讓步

**操作風格**：
- **推特/社交媒體治國** — 繞過傳統媒體、直接對話民眾
- **幕後操盤手** — 不站在前台、通過代理人/制度發力
- **個人魅力型** — 靠個人形象而非政黨機器、集會動員
- **制度建設者** — 通過立法/行政命令長期佈局
- **危機管理者** — 在危機中表現突出、善於應急

```
信息匯總：

  🏛️  {代號}
  🌍  {國家} {政黨} {職位}（若未填則省略）
  📅  活躍年代：{年代}（若未填則省略）
  📊  政治光譜：經濟 {X}/5，權威 {Y}/5（若未填則省略）
  🏷️   意識形態：{#標籤列表}（若未填則省略）
  ⚔️   風格：{#標籤列表}（若未填則省略）
  💬  印象：{印象文本}（若未填則省略）

確認無誤？（確認 / 修改 [字段名]）
```
