# 政治人物思維提取方法論

> 從原始語料到可運行的政治心智模型——提取、驗證、編碼的核心方法。
> 本文件改寫自 nuwa-skill `references/extraction-framework.md`，針對「政治人物」場景特化。

---

## 一、核心原則：HOW ≠ WHAT

本 Skill 要捕捉的是「這個政治人物**如何**思考」，不是「他**說過**什麼」。
- 一段口號如果無法推斷他對新議題的反應 → 無價值
- 一個投票模式如果能預測他在多個議題上的站位 → 這是心智模型

一句話：**刪掉名字之後，還能認出這是誰的思維方式**，才算成功。

---

## 二、心智模型的三重驗證

一個觀點要被認定為「政治心智模型」而非「隨口一說」，必須通過三重驗證。任何一條沒過，**降級或剔除**。

### 驗證 1：跨域復現（cross-domain）

同一個思維框架在此人討論**至少 2 個不同議題領域**時出現。

> 例：川普的「交易觀（everything is a deal）」
> - 外交：關稅、北約分攤金、北韓峰會
> - 司法：認罪協商、法官提名
> - 黨內：背書交換、籌款承諾
> → 跨 3 個領域復現 → 是心智模型

### 驗證 2：有生成力（predictive）

用這個模型能推斷此人對**新議題**的可能立場。

> 例：若柯文哲的「工程師思維（KPI/SOP 解決政治問題）」是心智模型——
> - 面對居住正義 → 他會算公式、建平台、設 KPI
> - 面對兩岸議題 → 他會要求「把 deliverable 列清楚」
> → 能生成新推斷 → 是心智模型

### 驗證 3：有排他性（distinctive）

不是每個同黨、同光譜的人都這樣想，這個模型體現了**此人獨特**的框架。

> 例：「不能讓孩子輸在起跑線」不是馬英九的，是華人家長都會說的 → 剔除
> 「以庶民感受決定政策」是韓國瑜明顯不同於傳統 KMT 菁英的視角 → 保留

**過門檻規則**：
- 通過 3 重 → 寫入「政治心智模型」（3-7 個為宜，太少=淺，太多=沒提煉）
- 只通過 1-2 重 → 降級為「決策啟發式」（具體可觸發的規則，5-10 條）
- 0 重 → 不納入

## 三、政治資產的證據權重（結構不變，配合三重驗證使用）

權重僅決定**可信度**；可信度高不代表有提取價值，仍須過三重驗證才能入模型。

| 等級 | 來源 | 用途 |
|------|------|------|
| 硬證據 | 投票、行政決策、正式政策文件 | 立場底座；與口號衝突時以此為準 |
| 公開表述 | 演說、辯論、訪談、社媒原文 | 修辭 DNA、敘事框架 |
| 外部觀察 | 媒體評論、對手攻擊、民調 | 驗證、反向推斷，**不能單獨作為結論** |
| 推斷 | 從標籤或模式推導 | 必須明確標註為 `推斷` |

**衝突處理**：不要合併成模糊結論；直接並列寫：
- `利益取向`（投票、決策真正方向）
- `公開敘事`（演說、社媒對選民的說法）
- `衝突點`（兩者具體差在哪）

## 四、表達 DNA 的量化

修辭風格不能寫成「有魅力、幽默、犀利」這種空話。必須量化。

### 4.1 句式指紋

從此人 20 段演說/訪談/貼文隨機取樣，統計：

| 維度 | 測量方式 |
|------|---------|
| 平均句長 | 字數 / 句數 |
| 疑問句比例 | 疑問句數 / 總句數 |
| 類比密度 | 類比數 / 千字 |
| 第一人稱使用率 | 「我」出現頻率 |
| 確定性語氣 | 「一定/絕對/顯然」vs「也許/可能/或許」 |
| 攻擊頻率 | 指名道姓批評次數 / 千字 |
| 情緒詞密度 | 情緒形容詞數 / 千字 |

### 4.2 風格光譜標籤

```
正式 ←→ 口語
抽象 ←→ 具體
謹慎 ←→ 斷言
菁英 ←→ 庶民
學理 ←→ 直覺
結論先行 ←→ 鋪陳型
數據驅動 ←→ 敘事驅動
```

### 4.3 禁忌詞與口癖

- **禁忌詞**：此人從不用的詞（如：扁的「大陸」從不出自他口，用「中國」）→ 生成 Skill 時也不用
- **口癖**：高頻標誌性表達（如：川普「Believe me」「Tremendous」）→ 適度使用，過度則變模仿秀

## 五、政治人物特有的矛盾處理

政治人物的矛盾是**人格核心特徵**，不是 bug。三種處理：

### 5.1 時間性矛盾（立場演化）
早期 vs 近期不同（例：蔡英文對兩岸論述從「中華民國台灣」到「中華民國憲政體制」）
→ 記錄演化軌跡，**以近期為主但保留早期**，標註轉折點與可能誘因（選情、黨內鬥爭、國際局勢）

### 5.2 場景性矛盾（對象切換）
對黨內一套、對記者會另一套、對國際社會第三套（例：許多政客對內「抗中」對外「維持現狀」）
→ 分場景記錄，**不強求統一**。寫清楚「對 X 受眾時說 Y，對 Z 受眾時說 W」

### 5.3 投票 vs 話術的本質張力（政治特有，最重要）
這是政治人物最有價值的部分——**硬證據與公開敘事的差距**。

> 例：某立委在社媒嚴厲批評某產業，但關鍵法案棄權或投贊成
> → 不能抹平，必須保留成「核心張力」：**利益結構（硬證據）** vs **政治表演（公開敘事）**
> 運行時這兩層都要體現——先用硬證據定底座，再用公開敘事包裝

### 錯誤處理
- ❌ 選一邊、忽略另一邊
- ❌ 編一個調和的解釋（「他只是策略性地……」）
- ❌ 假裝矛盾不存在

## 六、六軌並行研究建議

生成 Skill 時，用 6 個並行 research agent 分頭採集。每軌輸出獨立檔案存在 `politicians/{slug}/research/`：

| Agent | 焦點 | 輸出檔案 |
|-------|------|---------|
| 1 | 公開演說、辯論、就職演說、質詢稿 | `01-speeches.md` |
| 2 | 法案投票記錄、行政決策、政策文件 | `02-votes-decisions.md` |
| 3 | 社交媒體、即時發言、短影片 | `03-social-media.md` |
| 4 | 媒體評論、學術分析、對手攻擊 | `04-external-views.md` |
| 5 | 訪談、記者會、回憶錄、傳記 | `05-interviews-bio.md` |
| 6 | 時間線、重大轉折、近期動態 | `06-timeline.md` |

**約束**：所有研究產出**必須寫入 skill 目錄內**（`politicians/{slug}/research/`），不得散落到外部。這是 skill 可攜性的前提。

**並行優先順序**：若資源有限只能跑 3 軌 → 軌 1、2、3 優先（一手語料最硬）。

## 七、資訊不足時的處理

| 情況 | 處理 |
|------|------|
| 某維度公開資訊極少（如私下決策邏輯） | 標註「資訊不足，此維度為推測」 |
| 只有二手資訊 | 降低置信度，標註「據 [來源] 報導」 |
| 互相矛盾且無法判斷 | 並列呈現，讓用戶自行判斷 |
| 此人刻意不公開（如宗教觀） | 尊重邊界，註明「此人對此議題保持沉默」 |

**核心原則**：寧可誠實的 60 分 Skill，不要虛構的 90 分 Skill。

## 八、人物 Skill vs 議題 Skill

本 Skill 是**人物型**，下表釐清差異：

| 維度 | 人物 Skill（本專案） | 議題 Skill |
|------|---------------------|-----------|
| 核心 | 一個政治人物的思維 | 一個議題的多光譜觀點 |
| 心智模型來源 | 主要來自此人本身 | 綜合各派視角 |
| 表達風格 | 模擬此人語感 | 中性但專業 |
| 矛盾處理 | 保留此人內在矛盾 | 呈現流派間分歧 |
| 驗證方式 | 對比此人已知立場 | 對比領域內共識 |

## 九、品質自檢清單

生成 SKILL.md 後，逐條自檢：

### 政治心智模型
- [ ] 每個模型都有至少 2 個不同議題領域的證據？
- [ ] 模型數量在 3-7 之間？
- [ ] 每個模型都有明確的應用場景與局限？
- [ ] 模型之間有張力但不互相矛盾到崩潰？

### 決策啟發式
- [ ] 每條規則都有具體案例支撐（投票、演說、行動）？
- [ ] 可被新議題觸發（不只適用於原始案例）？
- [ ] 數量在 5-10 之間？

### 表達 DNA
- [ ] 讀起來有辨識度，不像通用政客？
- [ ] 沒有過度模仿變成 caricature？
- [ ] 抓住核心特徵而非表面口癖？

### 證據與邊界
- [ ] 每條核心結論都標註了證據等級？
- [ ] 投票與口號衝突時並列保留，沒有抹平？
- [ ] 明確寫了這個 Skill **做不到**什麼？
- [ ] 標註了研究截止日期？

### 整體
- [ ] 用此人的框架看一個**新議題**，能得到有價值的預測？
- [ ] 不是此人原話的拼貼，而是思維框架在運行？
- [ ] 刪掉名字後還能認出是誰的思維？
